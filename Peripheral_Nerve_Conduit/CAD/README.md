# Peripheral Nerve Conduit

## Overview

Parametric SolidWorks design of a peripheral nerve conduit for nerve regeneration.

## Design Objective

The objective was to develop a cylindrical nerve conduit concept capable of supporting peripheral nerve regeneration across a defined nerve gap.

## CAD Design

The conduit was developed using a feature-based parametric modelling workflow in SolidWorks.

The design incorporates an internal spiral fibre architecture intended to provide structural guidance within the conduit.

## Key Parameters

| Parameter | Value |
|---|---:|
| Overall length | 30 mm |
| Outer diameter | 4 mm |
| Wall thickness | 0.7 mm |
| Internal architecture | Spiral fibre |
| CAD software | SolidWorks |

## CAD Features

- Parametric cylindrical geometry
- Concentric features
- Helix/spiral geometry
- Swept fibre architecture
- Feature-based modelling
- Dimensional constraints

## Files

- `CAD/Parametric_PCL_Nerve_Conduit.SLDPRT` — SolidWorks part file

## Engineering Considerations

The design considers dimensional control, internal architecture and manufacturability for biomedical additive manufacturing applications.
