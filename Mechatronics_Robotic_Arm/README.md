# Robotic Arm – SOLIDWORKS Mechatronics CAD Project

## Overview

A CAD modelling project completed while following the **SOLIDWORKS: Design for Mechatronics** course on LinkedIn Learning.

The project focuses on developing components for a simplified robotic arm and applying parametric mechanical design techniques in SOLIDWORKS.

## Learning Objectives

This project was used to develop practical skills in:

* Parametric mechanical modelling
* Sketch-based feature creation
* Extrusions and cut features
* Hole Wizard
* Feature mirroring and patterns
* Draft and shell features
* Mechanical design for mechatronic systems
* Engineering drawings and design documentation
* CAD file preparation for manufacturing and 3D printing

## Software

* SOLIDWORKS
* LinkedIn Learning – SOLIDWORKS: Design for Mechatronics

## Project Files

* `CAD/` – SOLIDWORKS part and assembly files
* `Drawings/` – Engineering drawings
* `Images/` – CAD screenshots and project visuals
* `STL/` – Exported STL files

## Skills Demonstrated

**CAD:** Parametric 3D modelling, feature-based modelling, design intent

**Mechanical Design:** Component geometry, holes, patterns, draft and shell features

**Documentation:** Engineering drawings, dimensional definition and CAD file organisation
