# Projects

## 1. Peripheral Nerve Conduit

**Application:** Peripheral nerve regeneration
**Software:** SOLIDWORKS
**Design:** Parametric PCL nerve conduit

A parametric nerve conduit designed for peripheral nerve regeneration, incorporating an internal spiral fibre architecture.

The model demonstrates the translation of a biomedical engineering concept into a structured CAD design with controlled dimensions and defined internal architecture.

### Key Design Parameters

| Parameter             |        Value |
| --------------------- | -----------: |
| Length                |        30 mm |
| Outer diameter        |         4 mm |
| Wall thickness        |       0.7 mm |
| Internal architecture | Spiral fibre |

### CAD Features

* Parametric sketching
* Dimensional constraints
* Extruded geometry
* Sweep features

# Design Approach

My CAD work combines **biomedical engineering knowledge with structured engineering design**.

I focus on developing models that are:

* **Parametric** — dimensions and design intent are controlled through defined parameters.
* **Structured** — features and components are logically organised within the CAD model.
* **Application-driven** — designs are developed around specific engineering and biomedical applications.
* **Manufacturing-aware** — geometry is developed with fabrication and additive manufacturing considerations in mind.
* **Well documented** — engineering drawings and supporting documentation communicate the design clearly.
